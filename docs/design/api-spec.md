# API Spec: Agentic AI Migration Assistant

Companion to [tdd.md](tdd.md); entities in [data-model.md](data-model.md). **The source design specifies the API's behavior (validate, record, enqueue; approval gates; 403 without approval) but not concrete routes.** The endpoints below are a proposed surface derived from it; paths and field names are for review, not decided.

## Conventions

- **Base URL / versioning:** `/v1` URL prefix. Host TBD.
- **Auth:** Microsoft Entra ID OIDC bearer token. Roles: `viewer`, `analyst` (start runs), `reviewer` (approve), `admin` (register repos, set budgets). Enforced in the API and again by Postgres RLS on `tenant_id` (taken from the token, never from the request).
- **Format:** JSON, `snake_case`, Pydantic v2 schemas; OpenAPI generated by FastAPI (so this doc can be replaced by the generated file once code exists).
- **Error envelope:** `{ "error": { "code": "string", "message": "string", "run_id": "uuid|null" } }`
- **Idempotency:** `POST` that creates runs or approvals accepts `Idempotency-Key`. Run creation is also unique on `(repo, sha)` while active.
- **Rate limiting:** per tenant token bucket; `429` with `Retry-After`.
- **Pagination:** cursor-based, `?limit=&cursor=`; response `{ items, next_cursor }`.
- **Correlation:** every response carries `X-Run-Id` where applicable; same id appears in traces and audit.
- **Common errors:** 400 validation, 401 unauthenticated, 403 role/policy/approval missing (attempt is audited), 404 not found (also for other tenants' resources), 409 conflict/version mismatch, 429 rate limit.

## Endpoints

### `POST /v1/repositories`
**Purpose:** Register a repo for analysis. **Auth:** `admin`.
**Request:** `{ "provider": "github|gitlab", "url": "string", "installation_ref": "string", "protected": "bool" }`
**Response (201):** `{ "id": "uuid", "provider": "...", "url": "...", "protected": "bool" }`
| Status | Condition |
| --- | --- |
| 409 | Already registered |
| 422 | GitHub App not installed / unreachable |

### `GET /v1/repositories`
**Purpose:** List registered repos. **Auth:** `viewer`+. **Response (200):** paginated list.

### `PATCH /v1/tenant/budgets`
**Purpose:** Set default per-run token budget and monthly cap. **Auth:** `admin`.
**Request:** `{ "run_token_budget": "int", "monthly_token_cap": "int" }` **Response (200):** updated values.

### `POST /v1/runs`
**Purpose:** Start an analysis at a pinned SHA. Validates, writes `analysis_run`, enqueues; returns immediately. **Auth:** `analyst`+.
**Request:** `{ "repo_id": "uuid", "commit_sha": "40-hex", "token_budget": "int|null" }`
**Response (202):** `{ "run_id": "uuid", "status": "queued", "cached_code_model": "bool" }`
| Status | Condition |
| --- | --- |
| 403 | Repo not registered / role insufficient |
| 409 | Active run exists for repo+SHA (returns existing `run_id`) |
| 422 | SHA not found or not a 40-char hex |
| 429 | Rate limit or tenant monthly cap reached |

### `GET /v1/runs/{run_id}`
**Purpose:** Status, stage, budget used, model/prompt versions, flags (fallback model used, needs human review). **Auth:** `viewer`+.
**Response (200):** `{ "run_id", "repo_id", "commit_sha", "status", "stage", "budget": {"limit","used"}, "versions": {"models","prompt"}, "flags": ["fallback_used","verifier_exhausted"], "created_at", "finished_at" }`

### `GET /v1/runs`
**Purpose:** List runs, filter by `repo_id`, `status`. **Auth:** `viewer`+. Paginated.

### `POST /v1/runs/{run_id}/cancel`
**Purpose:** Stop a run. **Auth:** `analyst` (own) or `admin`. **Response (202).** Conflict (409) if already terminal.

### `GET /v1/runs/{run_id}/proposal`
**Purpose:** Latest (or `?version=n`) proposal with services, module assignments, rationale, evidence ids, and verifier violations. **Auth:** `viewer`+.
**Response (200):** `{ "version": "int", "services": [{"name","modules":[],"rationale","evidence_ids":[]}], "violations": [], "status" }`
**Errors:** 404 before a proposal exists.

### `GET /v1/runs/{run_id}/evidence/{evidence_id}`
**Purpose:** Resolve a cited evidence item (file, line, metric). **Auth:** `viewer`+.
**Response (200):** `{ "id", "kind", "file_path", "line", "metric", "snippet": "string|null" }`

### `POST /v1/runs/{run_id}/approvals/gate1`
**Purpose:** Approve, edit or reject the verified proposal. **Auth:** `reviewer`.
**Request:** `{ "decision": "approved|edited|rejected", "edited_proposal": "object|null", "reason": "string" }`
**Response (200):** `{ "approval_id", "run_status" }`; edits and rejections are written as `feedback` and episodic memory.
| Status | Condition |
| --- | --- |
| 403 | Not a reviewer |
| 409 | Run not awaiting gate 1, or `version` mismatch |
| 422 | `edited_proposal` fails schema or hard rules; `reason` missing on edit/reject |

### `GET /v1/runs/{run_id}/artifacts`
**Purpose:** List generated specs, plans, scaffolds and compile results per service, with Blob-backed download links. **Auth:** `viewer`+.
**Response (200):** `{ "services": [{"name","openapi_url","plan_url","scaffold_url","compile":{"passed","log_url"}}] }`
**Errors:** 403 if gate 1 not approved (artifacts are not exposed before it).

### `POST /v1/runs/{run_id}/approvals/gate2`
**Purpose:** Approve opening the draft PR, or stop. **Auth:** `reviewer`; for protected repos must differ from `initiated_by`.
**Request:** `{ "decision": "approved|rejected", "reason": "string" }`
**Response (202):** `{ "approval_id", "run_status": "opening_pr" }`
| Status | Condition |
| --- | --- |
| 403 | Four-eyes violation, or gate 1 not approved (audited) |
| 409 | Not awaiting gate 2; PR already opened |

### `GET /v1/runs/{run_id}/pull-request`
**Purpose:** Draft PR URL and status once opened. **Auth:** `viewer`+. 404 until created.

### `GET /v1/runs/{run_id}/audit`
**Purpose:** Audit trail for the run (LLM calls, tool calls, OPA decisions, approvals, PR actions). **Auth:** `reviewer`+ (admin for cross-run).
**Response (200):** paginated `audit_event` items. Prompts/outputs are in LangSmith under the same `run_id`, not here.

### `GET /v1/runs/{run_id}/metrics`
**Purpose:** Cost, tokens, stage durations, evaluation scores where ground truth exists. **Auth:** `viewer`+.

### `GET /healthz`, `GET /readyz`
Unauthenticated liveness/readiness (checks Postgres, Redis, Service Bus).
